헬스로그 UI v5

이번 수정
1. 홈 > 프로그램 수정
- 프로그램 안의 각 운동에 '↑ 위로', '↓ 아래로' 버튼 추가
- 버튼으로 운동 순서를 자유롭게 변경 가능
- 저장한 순서가 운동 탭에도 그대로 반영
- 프로그램 수정 시 기존 세트 유형을 최대한 유지

2. 운동 탭
- 오늘 날짜만 기록하던 방식에서 '운동 날짜' 직접 선택 방식으로 변경
- 오늘 또는 과거 날짜의 운동 기록 저장 가능
- 미래 날짜는 저장 불가
- 과거 날짜를 고르면 해당 날짜보다 이전의 최근 2회 운동 기록을 비교해서 표시
- 저장된 기록은 기록 탭 달력의 해당 날짜에 표시

기존 기능
- 프로그램 추가/수정/삭제
- 운동 개수 자유롭게 추가
- 운동별 세트 수 설정
- 워밍업/워킹/드롭 세트 선택
- 최근 2회 기록 비교
- localStorage 저장
- PWA 홈 화면 추가
