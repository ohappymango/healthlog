헬스로그 UI v2

기능
- 홈: 운동 프로그램 목록, 새 프로그램 추가
- 기록: 달력에서 운동 날짜 확인, 날짜별 운동 상세 확인
- 운동: 프로그램 선택, 운동별 전체 세트 표시, 최근 2회 무게/횟수 비교, 오늘 기록 입력
- 운동 저장: localStorage에 기기 내 저장
- PWA 구성: manifest + service worker + 홈 화면 추가 가능

사용
1. 압축을 풉니다.
2. index.html을 웹서버에 올립니다.
3. HTTPS 환경에서 접속합니다.
4. 휴대폰 브라우저 메뉴에서 '홈 화면에 추가'를 선택합니다.

주의
- localStorage는 해당 브라우저의 사이트 데이터에 저장됩니다.
- 브라우저 데이터 삭제 또는 기기 변경 시 기록이 사라질 수 있습니다.
