헬스로그 UI v4

이번 수정
- 홈 목록에서 프로그램 바로 삭제 가능
- 프로그램 삭제 시 기존 운동 기록은 기록 탭에 유지
- 운동 탭에서 각 세트마다 워밍업 / 워킹 / 드롭 유형 선택 가능
- 선택한 세트 유형이 프로그램에 저장되어 다음 운동에도 유지
- 오늘 운동 저장 시 세트 유형도 함께 기록
- 기존 최근 2회 기록 비교, 무게/횟수 입력, 달력 기록, PWA 기능 유지
